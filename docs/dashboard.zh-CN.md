# RoutePilot 线路测试仪表盘

仪表盘是一个中立的本地测试工具。它显示事实，不判断某个结果是否“优化成功”。

## 如何打开

先启动两条本地 HTTP 代理，然后双击项目根目录中的：

```text
Open-Dashboard.cmd
```

不需要安装 Node.js、Python 或浏览器扩展。

## 状态区显示什么？

- **自动分流已启用/未启用**：读取当前 Windows 用户的 Edge `ProxySettings`，并确认内嵌 PAC 是否由 RoutePilot 生成。
- **主线路端口**：检查配置中的住宅/可信 HTTP 代理能否建立本地 TCP 连接。
- **高速线路端口**：检查配置中的 VPS HTTP 代理能否建立本地 TCP 连接。

启动仪表盘本身不会修改注册表、切换节点、启动 TUN 或下载测速文件。

## 点击测速后发生什么？

仪表盘通过每个本地 HTTP 代理分别请求相同的 Cloudflare 测试文件。默认每条线路测试两次，每次 5 MB，然后显示：

- 每条线路两次结果的中位值，单位为 Mbps；
- 高速线路 Mbps 除以主线路 Mbps 得到的客观比例。

默认总测试流量约为 20 MB，其中约 10 MB 会经过主线路，约 10 MB 会经过高速线路。按流量付费时应把这部分计入套餐消耗。

## 怎样用于录制演示？

1. 打开仪表盘，记录当前策略状态和两条线路端口。
2. 点击“开始对比测速”，记录两条独立线路的数据。
3. 点击“运行配置向导”，根据提示安装 Edge 分流。
4. 重启 Edge。
5. 回到仪表盘，点击“刷新启用状态”。
6. 是否再次测速由你决定；策略状态变化与线路速度是两个不同指标。

## 如何理解数据？

- 仪表盘测的是两个代理路径到测试服务器的传输速度，不是某个具体网站的保证速度。
- 测速不会证明网站账号请求实际使用了哪一个公网出口；策略状态与 PAC 测试负责说明分流配置。
- 线路拥堵、VPS 带宽、住宅供应商、目标 CDN、丢包和测试时段都会改变结果。
- `Mbps` 是兆比特每秒，换算为常见下载软件显示的 `MB/s` 大约需要除以 8。

## 命令行读取

只读取状态、不下载文件：

```powershell
.\scripts\Get-RoutePilotSnapshot.ps1 -SkipBenchmark -AsJson
```

运行默认对比测速并输出 JSON：

```powershell
.\scripts\Get-RoutePilotSnapshot.ps1 -AsJson
```
